# Fitness Tracker Pro

Une application web locale moderne pour la gestion des entraînements de physiothérapie et de remise en forme. Elle utilise des données en format JSON générées à partir de bases CSV.

## Fonctionnalités
- Affichage des plans d'entraînement.
- Bibliothèque complète des exercices avec détails (répétitions, durée, repos).
- Modal moderne de détails avec intégration de recherche YouTube pour les vidéos.
- Barre de recherche et filtres par mots-clés.
- CLI Python de gestion (pour exporter les plans en Markdown).

## Technologies
- HTML, CSS (Custom Properties, Flexbox, Grid), JavaScript Vanilla.
- Python 3 (pour le CLI et le serveur web local de développement).
