# PhysioApp - Un guide d'entraînement kiné (Physiotherapy Workout Guide)

PhysioApp is a cross-platform (Mobile/Windows) web application designed to help you follow your physiotherapy exercises with timers, structured sequences, and helpful tips. It's built with React, Vite, and Tailwind CSS.

## 🚀 Comment démarrer / How to start the app

If the screen is entirely white when you open `index.html`, **you must run a local development server**. React applications cannot be opened directly from the file explorer.

### Étape 1 : Ouvrir le terminal dans ce dossier (Open terminal here)
Navigate to this `physioapp` folder in your terminal.

### Étape 2 : Installer les dépendances (Install dependencies)
Run this command once to install the necessary files:
```bash
npm install
```

### Étape 3 : Démarrer le serveur local (Start the local server)
Run this command to start the application:
```bash
npm run dev
```

### Étape 4 : Ouvrir votre navigateur (Open your browser)
Go to `http://localhost:5173` in your web browser (Chrome, Safari, Edge, etc.) to view PhysioApp!

## 📱 Features

*   **Workout Sequences:** Guided workouts with timers for exercises and rest periods.
*   **"Advance When Ready":** The timer automatically pauses at the start of every exercise. You click "Play" when you are in position.
*   **Exercise Library:** View detailed instructions and "Pro Tips" for each movement.
*   **Responsive Design:** Looks great on your phone or on your desktop computer.
