# Directives pour les Agents IA (AGENTS.md)

Ce fichier définit les règles strictes de contribution pour les agents IA sur ce repository. Lisez-le avant chaque session.

## 1. Processus de Travail
- **Planification :** Toujours réfléchir et planifier avant de modifier le code (`Deep Planning`). Valider les hypothèses avec l'utilisateur.
- **Vérification :** Chaque modification doit être vérifiée (ex: lecture de logs, tests, lancement de commandes locales).
- **Propreté :** SUPPRIMEZ TOUS LES FICHIERS TEMPORAIRES (scripts de test, logs générés) avant de clore une tâche. Le nettoyage est obligatoire.

## 2. Documentation et Suivi
- Mettez systématiquement à jour `docs/WORKLOG.md` (déplacer les tâches de 'À faire' -> 'En cours' -> 'Fait').
- Si vous modifiez des structures de données ou l'architecture système, mettez à jour `docs/ARCHITECTURE.md`.

## 3. Communication
- Langue requise : Français.
